# 力氣錘

夜市大力王風格的揮錘遊戲。蓄力後抓準落槌節奏，讓紅色指標沿木塔向上衝；抵達塔頂即可敲響金鐘。

## 玩法

- 按住「蓄力揮錘」（鍵盤可按住空白鍵）累積力氣。
- 游標進入右側金色落槌區時放開，力量與節奏共同決定指標高度。
- 高度分為「輕／中／重／響鈴」；越過響鈴門檻另加 250 分，最高 999。
- 本局最佳保留到按「新局」；最高紀錄存於 `/api/kv/pg-strongman-best`，KV 不可用時仍可遊玩。

## 本機試玩與測試

```bash
python3 -m http.server 8080
npx --yes vitest@latest run
```
